# Sabari Folio Gradients

## Project Overview

This project is a modern and responsive portfolio website designed to showcase skills, projects, and experiences. It features:

- **Dynamic Animations**: Smooth and engaging animations using Framer Motion.
- **Responsive Design**: Optimized for all devices, including desktops, tablets, and mobile phones.
- **Interactive Components**: Custom-built UI components for an enhanced user experience.
- **Dark Mode Support**: Seamless switching between light and dark themes.

## Technologies Used

- **React**: For building the user interface.
- **TypeScript**: Ensuring type safety and better developer experience.
- **Tailwind CSS**: For styling and responsive design.
- **Vite**: A fast build tool for modern web projects.
- **Framer Motion**: For animations and transitions.

## Features

1. **Navbar**: A responsive navigation bar with a dark mode toggle.
2. **Projects Section**: Displays a grid of projects with a "Show More" feature for mobile devices.
3. **Skills Section**: Highlights technical skills with water dance-like animations that play once when viewed.
4. **Contact Section**: A form to get in touch.
5. **Scroll to Top Button**: For easy navigation.
6. **404 Not Found Page**: Custom error page for undefined routes.
7. **Mobile-First Design**: Optimized for mobile and tablet users.

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone <YOUR_GIT_URL>
   cd sabari-folio-gradients-main
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Start the development server:**
   ```sh
   npm run dev
   ```

## Deployment

You can deploy this project using platforms like Vercel, Netlify, or any static hosting service. Build the project and upload the `dist` folder.
